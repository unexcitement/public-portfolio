## Compiling Visual Diagrams via Ephemeral Docker

All visual documentation is defined using raw Mermaid (`.mmd`) specifications. In accordance with zero-host-pollution standards, **no global NPM packages or host dependencies are required** to render these diagrams into production vector graphics (`.svg`).

To batch-compile all 52 project diagrams into standalone `.svg` vectors using an ephemeral throw-away container:

```bash
chmod +x scripts/compile_diagrams.sh
./scripts/compile_diagrams.sh
```

Or execute an ad-hoc compilation for any individual diagram:

```bash
docker run --rm -v "$(pwd):/data" minlag/mermaid-cli \
    -i /data/projects/01-event-sourcing-operations-hub/diagrams/architecture.mmd \
    -o /data/projects/01-event-sourcing-operations-hub/diagrams/architecture.svg
```
